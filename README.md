I had trouble deploying the project from page 1-5 in Vercel. What needed to be done was to update the tyscript, because the tyscript was outdated to an earlier version, 5.4

terminal : pnpm update typescript@latest

The tyscript needed to be updated and equal to:

"ignoreDeprecations": "6.0"
